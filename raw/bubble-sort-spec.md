# 泡沫排序功能規格

## 功能描述

有一個排序函數，接收整數數組作為輸入，返回從小到大排序後的數組。

## 算法行為

1. 從數組第一個元素開始
2. 比較當前元素與下一個元素
3. 如果當前元素較大，則交換位置
4. 移動到下一個元素，重覆步驟 2-3 直到數組末尾
5. 重覆整個流程，直到某次遍歷中沒有發生任何交換

## 輸入/輸出

- 輸入：`[5, 3, 8, 4, 2]`
- 輸出：`[2, 3, 4, 5, 8]`

## 邊界條件

- 空數組：返回空數組
- 單元素數組：返回原數組
- 已排序數組：返回原數組（不交換）

## 效率

- 時間覆雜度：O(n²)
- 空間覆雜度：O(1)（原地排序）
