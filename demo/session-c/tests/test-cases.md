# Session C：測試用例設計

##測試者角色

**測試驗證者**：不看原程式碼實現，只對比輸入/輸出行為。

---

##測試用例清單

### 類型 1：正常流程測試

|編號 |操作 |輸入 |預期輸出 |
|----------|------|------|----------|
| TC-001 | INFO日誌記錄 |訊息：「使用者登入成功」 |檔案包含日誌行，返回 True |
| TC-002 | WARN日誌記錄 |訊息：「資料庫連線延遲」 |檔案包含日誌行，返回 True |
| TC-003 | ERROR日誌記錄 |訊息：「系統錯誤」 |檔案包含日誌行，返回 True |

###類型 2：等級過濾測試

|編號 |操作 |輸入 |預期輸出 |
|----------|------|------|----------|
| TC-004 | DEBUG（最小等級INFO） |訊息：「除錯資訊」 |不記錄，返回 False |
| TC-005 | INFO（最小等級WARN） |訊息：「一般資訊」 |不記錄，返回 False |
| TC-006 | WARN（最小等級WARN） |訊息：「警告」 |記錄，返回 True |

###類型 3：邊界條件測試

|編號 |操作 |輸入 |預期輸出 |
|----------|------|------|----------|
| TC-B01 | 空訊息 |訊息：「」 |可記錄空行（規格未明確） |
| TC-B02 | 最小等級設定 |等級：DEBUG |設定成功，返回 True |
| TC-B03 | 等級設定查詢 |無 |返回當前等級 |

###類型 4：已處理狀態測試

|編號 |操作 |輸入 |預期輸出 |
|----------|------|------|----------|
| TC-S01 | 多次記錄 |連續3條日誌 |檔案包含3條記錄 |
| TC-S02 | 等級切換 |設定DEBUG後記錄 |DEBUG日誌被記錄 |

###類型 5：錯誤輸入測試

|編號 | 操作 |輸入 |預期輸出 |
|----------|------|------|----------|
| TC-E01 |無效檔案路徑 |路徑：不存在的目錄 |返回 False或建立檔案 |

---

##測試執行計劃

1.分別在 JS（原程式碼）和 Python（新實現）環境執行測試
2. 對比輸出結果（日誌檔案內容、返回值）
3. 不對比程式碼結構
