# 日誌模組功能規格

## Session A：規格提取

**提取者角色**：規格編寫者（可看原程式碼，但只提取功能描述）

---

## 1. 功能名稱

日誌記錄模組（Logger Module）

---

## 2. 功能描述

將程式執行過程中的重要事件記錄到儲存媒體，供後續查詢與分析。支援不同日誌等級，可根據等級過濾記錄內容。

---

## 3. 輸入規範

### 3.1 初始化輸入

| 輸入 |類型 | 說明 |預設值 |
|------|------|------|--------|
| 日誌檔案路徑 | 字串 |日誌寫入的檔案位置 | `'app.log'` |
|最小日誌等級 | 數值/枚舉 | 只有達到此等級才會記錄 | INFO（等級 1） |
|時間格式 | 字串（可選） |時間戳記的格式 | ISO 格式 |

### 3.2 日誌記錄輸入

| 輸入 |類型 |說明 |
|------|------|------|
|日誌訊息 | 字串 | 要記錄的內容 |
| 日誌等級 |枚舉 | DEBUG / INFO / WARN /ERROR |

---

## 4.輸出規範

### 4.1 日誌記錄輸出

|輸出 |類型 | 說明 |
|------|------|------|
|日誌檔案 | 文字檔案 | 持久化儲存的日誌內容 |
|寫入結果 | 成功/失敗 | 是否成功寫入 |

### 4.2 日誌檔案格式

每條日誌記錄格式為：
```
[時間戳記] 日誌等級: 日誌訊息
```

範例：
```
[2026-04-27 16:30:00] INFO:使用者登入成功
[2026-04-27 16:31:00] ERROR:資料庫連線失敗
```

---

## 5. 日誌等級定義

|等級 |順序 |說明 |
|------|------|------|
| DEBUG |最低 |除錯資訊，開發階段使用 |
| INFO | 中低 |一般資訊，正常執行事件 |
| WARN |中高 |警告資訊，潛在問題 |
| ERROR |最高 |錯誤資訊，嚴重問題 |

等級過濾規則：**只記錄等級 ≥ 最小等級的日誌**

---

## 6.邊界條件

|情況 |處理方式 |
|------|----------|
| 空日誌訊息 | 可記錄空行或跳過（未明確定義） |
| 日誌等級低於最小等級 | 不記錄，返回失敗 |
| 日誌檔案無法寫入 |返回失敗，可輸出錯誤訊息到控制台 |
|無效日誌等級 |不記錄或使用預設等級（未明確定義） |
| 日誌檔案不存在 | 自動建立新檔案 |

---

## 7. 行為預期

### 7.1 日誌記錄行為

1.接收日誌訊息與等級
2.判斷等級是否 ≥最小等級
3. 若不符合則不記錄
4. 若符合則格式化日誌內容
5. 寫入日誌檔案
6.返回成功/失敗結果

### 7.2 等級設定行為

1. 接收新的最小等級
2. 判斷等級是否在有效範圍
3. 若有效則更新設定
4. 返回成功/失敗結果

---

## 8.使用範例

###範例 1：基本日誌記錄

```
初始化：
日誌檔案 = 'myapp.log'
最小等級 = INFO

操作：
記錄 INFO 等級日誌：「使用者登入成功」

結果：
myapp.log 檔案內容：
[2026-04-27 16:30:00] INFO:使用者登入成功
```

###範例 2：等級過濾

```
初始化：
最小等級 = WARN

操作：
記錄 DEBUG 等級日誌：「除錯資訊」

結果：
不記錄（DEBUG < WARN）
返回失敗
```
