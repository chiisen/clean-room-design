# Session B：實現記錄

##實現者角色

**移植開發者**：不看原程式碼，只看規格文件實現新語言版本。

---

##實現決策

### 1.語言選擇

選擇 Python 作為新實現語言，原因：
- 跨平台通用性
- 內建檔案操作支援
- 清晰的枚舉類型（`IntEnum`）

### 2. 架構設計

根據規格文件，設計以下結構：

| 組件 |說明 |
|------|------|
| `LogLevel` | 日誌等級枚舉（DEBUG/INFO/WARN/ERROR） |
| `Logger` | 日誌記錄器類別 |

### 3.實現細節

#### 3.1時間戳記格式化

使用 Python 的 `datetime.now().strftime()`實現 ISO 格式時間戳記。

#### 3.2檔案寫入

使用 Python 的`with open()`進行追加寫入，確保：
- 檔案不存在時自動建立（`Path.touch()`）
- 使用 UTF-8編碼
-失敗時輸出錯誤到控制台

#### 3.3等級過濾

使用 `IntEnum`的數值比較實現等級過濾邏輯。

### 4.規格未定義的處理

規格文件中部分邊界條件未明確定義，實現時的決策：

| 未定義情況 |實現決策 |原因 |
|------------|----------|------|
| 空訊息處理 | 可記錄空行 | 規格允許，不限制 |
|無效等級 | `set_min_level` 返回 False | 使用枚舉確保等級有效 |
| 日誌檔案不存在 | 自動建立 | 符合規格「自動建立新檔案」 |
